# 🚨 Kubernetes Error: Ingress Not Working
📌 What does "Ingress Not Working" mean?

An Ingress manages external HTTP/HTTPS access to services in a Kubernetes cluster. If the Ingress is not working, traffic from users does not reach the backend application.

Common symptoms:

❌ Website returns 404 Not Found
❌ 502 Bad Gateway
❌ 503 Service Unavailable
❌ Connection Timed Out
❌ Domain name is not accessible
