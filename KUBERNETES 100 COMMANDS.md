## 🚀 THE KUBERNETES 100 COMMANDS — Ultimate Cheat Sheet

| 🌐🧩 Cluster Info      | `kubectl api-versions`                                          | Displays all enabled API versions in cluster.                                                                                  | 🧪 Verify deprecated/new APIs                    |
